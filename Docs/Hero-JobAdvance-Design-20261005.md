# 영웅 성장 = 전직관 건물 + 전직 연구 — 설계 (2026-10-05)

- 상태: **구현 완료(2026-10-05) — Maker 미검증**. 구현 내용·Maker 할 일은 맨 아래 11장. 수치는 전부 1차 안, 2인 테스트 후 조정.
- 10-05 확정: 블래스터 교관 = **일렉스**(2159488), 제논 교관 = **지그문트**(1540452), 영웅은 **Q만 가지고 시작** → W·E·R·T를 2차~5차 전직으로 하나씩 연다.
- 결정 배경: 경험치(광맥·처치) 방식은 초반 성장이 사냥·킬 운에 좌우되고 "영웅을 먼저 키우는" 빌드가 정답이 되기 쉽다 → **건물을 짓고 전직을 연구해 스킬을 해금**하는 방식으로 확정.
- 원칙: **실제 메이플스토리 전직관 리소스를 최대한 쓴다.** 교관 NPC는 영웅마다 실제 전직 교관, 건물은 진영 마을 오브젝트, 완료 연출은 메이플 이펙트·효과음.
- 미리보기: `Docs/preview/job_advance_resources.png` (아래 리소스 전부 한 장)

---

## 1. 한 줄 요약

진영마다 **전직관 건물**(1개 한정)을 짓는다 → 전직관을 선택하면 **초상 칸에 내 영웅의 실제 메이플 전직 교관 NPC**가 나온다(맵에는 건물만) → 건물을 선택해 **2차~5차 전직 연구** → 완료될 때마다 영웅 스킬 하나가 열리고 영웅 머리 위에 전직 이펙트가 터진다.

## 2. 진행 구조

| 단계 | 해금 스킬 | 이름 예(모험가 다크나이트) | 연구 조건 | 비용 | 연구 시간 |
|---|---|---|---|---|---|
| 시작(1차) | **Q** | 검사 | — | — | — |
| 2차 전직 | **W** | 스피어맨 | 전직관 | 메소 75 | 20초 |
| 3차 전직 | **E** | 버서커 | 전직관 | 메소 125 | 35초 |
| 4차 전직 | **R** | 다크나이트 | 전직관 + 진영 테크 건물 | 메소 175 · 에르다 1 | 45초 |
| 5차 전직 | **T**(궁극기) | 다크나이트 (5차) | 전직관 + 진영 최종 테크 건물 | 메소 250 · 에르다 2 | 60초 |

- 영웅은 **Q(쿨 0 기본기) 하나로 시작**한다. 초반 영웅은 평타형이고, 첫 전직(W)이 싸서 빨리 열리게 해 "영웅이 할 게 없는" 구간을 짧게 둔다.
- 메이플에도 5차 전직이 있어서 T(쿨 45~120초 궁극기)를 5차에 둔다.
- 전직마다 영웅 **최대 체력·공격력 +6%**(누적 최대 +24%) — 스킬 하나만 느는 것보다 "성장했다"는 체감이 확실하다. (선택 항목, 테스트 후 결정)
- 경험치·레벨은 **두지 않는다.** HUD의 레벨 표시 자리는 "N차"로 쓴다.

## 4. 플레이 흐름

1. 일꾼 건설 목록에 **전직관** 추가(진영당 1개만, 이미 있으면 잠금 "전직관은 하나만 지을 수 있습니다").
2. 완공된 전직관을 선택하면 **초상 칸(원래 유닛 애니메이션이 나오는 자리)에 내 영웅의 교관**이 나온다. 맵에는 교관을 세우지 않는다(10-05 결정). 상대 전직관을 선택해도 그 플레이어의 교관이 보인다 — 정찰의 보상.
3. 전직관 선택 → 커맨드카드 1칸 **"2차 전직"**(아이콘 = 교관 얼굴 썸네일, 툴팁 = 이름[단축키] / 비용 / 해금 스킬 이름 / 필요 조건 빨강 — 기존 SC2 툴팁 재사용).
4. 연구 중: 건물 생산 큐 칸에 진행 표시(기존 StructureProductionQueue 재사용), 교관 `say` 재생 + 말풍선.
5. 완료: 영웅에게 이펙트·효과음, 토스트 **"2차 전직 완료 — W 라만차 스피어 사용 가능"**, 스킬 칸 잠금 해제, 영웅 이름표 "스피어맨"으로 변경.
6. 다음 전직 버튼이 같은 자리에 나타난다(조건 미달이면 어둡게 + 마우스 올리면 필요 조건).

## 5. 규칙

- 전직 단계는 **플레이어 단위**(`PlayerInfo.JobTier`)로 저장 → 영웅이 죽었다 부활해도 유지.
- 연구는 한 번에 하나, 순서대로만(2→3→4→5).
- **연구 중 전직관이 파괴되면** 연구 취소, 비용 **환불 없음**(지켜야 할 이유). 이미 끝난 전직은 유지. 다시 지으면 이어서 연구 가능.
- 영웅이 죽어 있는 동안 연구가 끝나면 부활할 때 적용(토스트는 즉시).
- 잠긴 스킬: 스킬 칸 어둡게 + 마우스 올리면 "3차 전직 필요 — 전직관에서 연구". 시작 직후엔 W·E·R·T 네 칸이 잠겨 있다. 단축키를 눌러도 **서버가 거부**(조작으로 우회 불가).
- 경기 종료 시 `ResetPlayerInfo`에서 1차로 초기화.

## 6. 경험치 방식 대비 장점 (요약)

- 초반 빌드가 사냥 운에 안 묶인다 — 전직은 비용·시간으로 밸런스를 숫자로 맞춘다.
- "군대냐 영웅 테크냐"라는 RTS다운 자원 선택이 생기고, 전직관 견제라는 공략 대상이 생긴다.
- 영웅은 전직하러 자리를 비우지 않는다(조작 부담 없음).
- 기존 건물·해금 조건·커맨드카드·툴팁·안개 잔상·생산 큐를 그대로 써서 구현 위험이 낮다.
- 메이플 느낌은 실제 교관 NPC·마을 건물·전직 이펙트·직업 이름 변화로 살린다.

## 11. 구현 (2026-10-05)

### 결정 사항 반영
- 교관 NPC는 **UI로만**: 전직관 선택 시 초상 칸(UnitSpriteUI)에 교관 애니메이션(평소 stand, 연구 중 say/지그문트는 sit). 맵에는 건물만.
- 일꾼 건설 목록을 스타 SCV·프로브처럼 **B 기본 건설 / V 고급 건설** 두 목록으로 나눴다(시그너스 건설 칸 9개가 꽉 차 있던 문제 해결).
  - 시그너스 기본: 기사단 병영·기사단 훈련소·여제의 알현실·신수의 가호·**기사단장의 수련장** / 고급: 골렘의 사원·기사단 사령부·정령의 제단·정령의 성소·시그너스 신전
  - 에델슈타인 기본: 안드로이드 공장·에델슈타인 정비소·레지스탕스 연구소·임시 거주구·**레지스탕스 교관실** / 고급: 폐광 무기고·에델슈타인 발전소·비행선 격납고·레지스탕스 사령부
  - 모험가: 스포아가 짓는 건 스포아 군락·**전직관의 집** 둘뿐이라 B 한 목록(V 없음).
  - 분류는 일꾼 모델 `WorkerAction.AdvancedSlots`(고급 목록에 넣을 슬롯 번호, 쉼표)로 바꾼다. V 아이콘 = `UIResources.CmdBuildAdvanced`(황금 망치 9e0443dd).

### 동작
- 전직관 커맨드카드: 2차~5차 버튼 4칸(단축키 Z/X/C/V). 끝난 단계는 "N차 완료"(어둡게), 다음 단계만 누를 수 있고 그 뒤는 잠금. 툴팁 = "N차 전직 — 직업 이름 [단축키]" / 메소·에르다·시간 / 초록 "해금: W 라만차 스피어" 또는 빨강 "필요: …".
- 연구 중: 그 칸에 남은 시간 덮개, 정보 패널에 "N차 전직 연구 중 · 12.3s 남음" + 진행 바, 초상 칸 교관이 말하는 동작.
- 완료: PlayerInfo.JobTier +1 → 영웅 스킬 칸 잠금 해제, 토스트 "2차 전직 완료! W 스킬 사용 가능 — 라만차 스피어", 영웅 머리 위 전직 이펙트(**A 황금 문장으로 확정**, `JobAdvanceLogic.CompleteEffectRuid`, 안개 속이면 그 클라엔 안 보임) + 레벨업 효과음.
- 영웅 스킬: 시작은 Q만. 잠긴 칸은 어둡게 + "N차 전직(전직관) 필요". 서버(HeroUnitSkill.RequestCast/CastSkill)도 거부. 영웅 정보 패널 이름이 전직 단계 이름(검사 → 스피어맨 …, 그 외 "소울마스터 (2차)").
- 연구 중 전직관 파괴/취소 → 연구 취소, 환불 없음. 경기 종료 시 1차로 초기화(LobbyController.ResetPlayerInfo).
- 수치·조건은 `JobAdvanceLogic` 인스펙터(Tier2Meso … EdeTier5Cond)에서 바꾼다.
