# 안개(전장의 안개) — 스타크래프트식 화면 덮개 (2026-10-05)

## 이전 상태
시야 판정(`VisionLogic`)은 시야 밖 **적 유닛·건물을 숨기기만** 했다. 맵 자체는 늘 밝아서 "적이 그냥 사라지는" 느낌이었다(Vision-Spec에서 안개는 다음 단계로 미뤄 둠).

## 지금 동작
| 지역 | 화면 | 기준 |
|---|---|---|
| 한 번도 안 가 본 곳 | 검게(불투명도 1.0) | 경기 시작 시 전부 이 상태 |
| 가 봤지만 지금 시야 밖 | 어둡게(0.55) | 내 유닛·건물 시야원이 한 번이라도 덮은 칸 |
| 지금 시야 안 | 밝게(0) | 내 유닛(살아 있는 것) + 내 건물(건설 중은 반경 50 %) 시야원 |

- 시야원은 적 숨김과 **같은 원**(`VisionLogic.CollectSources`)이라 "밝은데 적이 안 보임" 같은 어긋남이 없다. 본진 6.0, 영역·테크 5.0, 생산 4.5, 유닛은 CSV `vision ÷ 50`.
- 경계는 1 월드 유닛에 걸쳐 부드럽게 번지고, 밝기 변화는 0.25초 정도로 서서히 바뀐다.
- 안개 속(어두운 곳)에서는 적 유닛·건물과 **중립 몬스터(Arda 등)도 안 보인다**(스타처럼 시야 안에서만). 중립 건물·Arda 드롭은 보인다. 서버 전투 판정은 바뀌지 않았다.
- 탐사 기록은 내 화면에만 있다. 경기 맵을 떠나면 지워지고 다음 경기는 다시 검게 시작한다.

## 구현
- 신규 `PlayMap/Combat/FogOfWarLogic.mlua`(@Logic, 클라 전용). 검은 칸 `FogCell`(흰 사각형 100px 스프라이트 = 1 월드, 0.5 월드 칸, `MapLayer0` 순서 1000 → 유닛·건물·이펙트 위, HUD 아래)을 **화면 크기만큼만**(PC 기준 약 29×18 = 520개) 클라 로컬로 만든다.
- 칸은 월드 격자에 고정. 카메라가 움직이면 화면 밖으로 나간 줄만 반대편으로 옮겨 재사용한다(매 프레임 위치 쓰기는 바뀐 칸만).
- 0.15초마다 시야원 주변 칸만 밝기를 다시 계산(전체 맵을 돌지 않음). 네트워크 사용 없음.
- 신규 모델 `RootDesk/MyDesk/Models/MapObjects/FogCell.model`(model id `fogcell`).
- `VisionLogic.ApplyFor`: 중립 유닛도 시야 밖이면 숨김(안개 켜짐일 때만).

## 조절값 (Maker → FogOfWarLogic 인스펙터)
`칸 크기`(0.5, 작을수록 부드럽지만 칸 수 증가 — 0.4면 약 800개), `미탐사 지역 불투명도`(1.0), `탐사한 지역 불투명도`(0.55), `시야 경계 번짐 폭`(1.0), `밝기 변화 속도`(4.0), `안개 켜기`(끄면 예전처럼 밝은 맵 + 적 숨김만).

## 알려진 한계
- 이펙트는 **재생 시작 순간**의 위치로만 판단한다. 시야 안에서 시작한 반복(루프) 이펙트가 안개 속으로 따라 들어가면 계속 보일 수 있다.
- 투사체·연출 엔티티 숨김은 0.2초 주기라 안개 경계에서 순간적으로 보였다 사라질 수 있다.
- 효과음: 유닛 소리는 원래 숨겨진 대상이면 안 나지만, 영웅 스킬 소리는 위치 판정을 하지 않는다.

## 시작 렉 대응 (같은 날 3차)
경기 시작 순간 안개 칸 약 520개 스폰 + 미니맵 안개 칸 약 650개 복제가 한 프레임에 몰려 렉이 생길 수 있어, 둘 다 **프레임당 60개씩 나눠** 만든다(화면 안개 약 9프레임, 미니맵 약 8프레임에 완성). 미니맵 안개 칸은 2.5 → 3 월드로 키워 약 440개로 줄였다(미니맵 크기는 그대로, 안개 경계만 조금 더 각짐). 조절값: FogOfWarLogic "프레임당 안개 칸 생성 수", MinimapController "프레임당 미니맵 안개 칸 생성 수"·"미니맵 안개 칸 크기".

## 모자이크 개선 + 쿨타임 덮개 (같은 날 4차)
- **모자이크 개선:** 실행해 보니 0.5칸 네모가 그대로 보여 모자이크 같았다. 이제 칸마다 가장자리가 흐린 원(리소스 `e439962b…`, 64px "blur circle")을 **칸의 3배 크기**로 겹쳐 깐다. 이웃 점끼리 번져 스타2처럼 부드러운 그라데이션이 된다. 겹치면 진해지는 만큼 점 하나의 불투명도를 `k = 1-(1-목표)^(1/1.8)`로 낮춰 보정했다(실측: 목표 0.55 → 칸 안 어디서나 0.51~0.59, 미탐사는 96 % 이상 검정). 판정 로직(칸·탐사·시야)은 그대로다. 점이 칸보다 커서 화면 밖 여유 줄을 3줄로 늘렸다(약 670개, 프레임당 60개씩 생성).
- 조절값(FogOfWarLogic): `안개 점 스프라이트`, `안개 점 크기(칸 크기의 배수)` 3.0, `겹침 보정 계수` 1.8. 점 크기를 바꾸면 보정 계수도 다시 맞춰야 한다(2.5배 ≈ 1.4).
- **미니맵 안개는 네모 유지:** 미니맵 칸이 약 15px라 흐린 점을 쓰면 미니맵 테두리 밖으로 번진다. 스타 미니맵도 각진 방식이다.
- **목업:** `Docs/preview/fog_mock.png` / `fog_mock.html`(이전 네모 vs 이후 흐린 점, 같은 장면·같은 수치). 생성 도구 `메이플RTS_tools/fog_mock/build_fog_mock.py`.
- **쿨타임 덮개(별건):** 영웅 스킬 칸의 쿨타임 덮개가 둥근 모서리 기본 그림 + 원형 채우기라 동그랗게 돌았다. 흰 정사각형 그림으로 바꾸고 아이콘과 같은 72×72·같은 위치로 맞췄다(10칸, `ui/UIGroup.ui` `UnitActionUI/Slot*/Cool`). 이제 네모 아이콘 위에서 네모 모양으로 시계 방향으로 걷힌다.
