## 2. 서버 코어 (PlayMap)

### 확인된 버그
- **[0-1] `RequestSpawnUnit`** — `binfo.PlayerID == UserId` 검사 없음. `sact:GetConditionForModel(UnitModelID)`가 슬롯에 없는 모델이면 `nil`을 돌려 조건 검사를 통과. `building == nil`이면 플레이어 위치에 스폰하고 큐 4개 제한도 건너뜀. 수정: `not isvalid(building)`/`PlayerID ~= UserId`/`cond == nil` 모두 거부.
- **[0-1] 요청자 ≠ 컴포넌트 소유자** — `SpawnUnit.mlua` :13, :263, :368이 `self.Entity.PlayerComponent.UserId`만 쓰고 `senderUserId`와 비교하지 않음. 세 Server 메서드 첫 줄에 `if senderUserId ~= UserId then return end`.
- **[0-2] `RequestBuildStructure`** — `BuildTime`은 음수만 0으로 보정. 서버가 `SelectedCampStructure(camp)[ModelId].BuildTime`에서 직접 읽도록. 겹침(OverlapBox)·일꾼 근접(0.15)도 클라만 검사.
- **[0-3] MeleeSwarm 환불** — `SetUnitdata`가 각 마리에 전체 비용을 넣음. `cost / AbilityValue`로 나누거나 생산 그룹 단위 1회 환불.
- **[0-4] 인구** — `RequestSpawnUnit`에 인구 비교 없음. 서버에서 `MyUnits` 인구 합 + `Structure_Info.PopulationProvide` 합으로 거부. 영웅 유닛은 `MyUnitData`에 없어 HUD에서도 0으로 집계됨.
- **[0-5] 파괴 건물 미삭제** — `Structure_Info.GetDamage`는 `IsDestroyed=true` + 파괴 애니만. `Destroy()` 호출은 취소 경로(`SpawnUnit` :191, :220, :412)만. 잔존 `TriggerComponent`가 `BuildGhostComponent.CheckPlacementValid`의 `{"Unit","Structure","Monster"}` 겹침에 걸림.
- **[0-6] `SpawnUnitNow`** — 건물 유효성/`IsDestroyed` 재검사 없음.
- **분수 피해가 `integer Hp`에 대입** — `StructureBuffAura.mlua` :65, `SpecialAbilityComponent.mlua` :82가 `weapon.damage = damage * 1.1`(8.8) → `Unit_Info.GetDamage`에 floor 없음. `GetDamage` 첫 줄에 `damage = math.floor(damage)`.

### 설계 리스크
- `Weapon.AttackTarget` :154-155가 매번 `AttackCoolTime/damage`를 `Unit_Info`에서 다시 복사 → 저주(`ApplyAttackSlow`)·오라 버프가 대상 재지정 시 소실. 오라 2종(`StructureBuffAura.Tick`, `SpecialAbilityComponent.ApplySupportBuff`)이 같은 필드를 절대값으로 덮어써 마지막 쓴 쪽이 이김. 배율 누적 구조로 바꿔야 함.
