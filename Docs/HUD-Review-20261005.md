# 인게임 HUD 검토 — 초안 대비 실제 `.ui` (2026-10-05)

비교 기준은 HUD 초안 v2(https://claude.ai/artifact/Jz31Ww1RActSWiWVn8sWYd)다. 실제 화면은 `ui/UIGroup.ui` 값에 `FactionTheme` 진영 덧칠과 HUD 스크립트의 상황별 표시 규칙을 그대로 적용해 재현했다.
- 재현: `Docs/preview/hud_mock.html`. 진영 3개 × 상황 4개(선택 없음 / 유닛 1기 / 여러 기 / 건물 생산 중)를 바꿔 볼 수 있다.
- 캡처: `Docs/preview/hud_Adv_unit.png`, `hud_Cyg_multi.png`, `hud_Ede_bld.png`.

## 결론
대기실과 달리 인게임 HUD는 **목업과 실제가 어긋나는 구조적 문제가 없다**. 스프라이트 114개가 전부 엔진 기본 스프라이트이고 템플릿 아트를 쓰지 않는다. 색은 `.ui` 값과 `FactionTheme`가 정한다. 배치(미니맵·정보 패널·초상화·커맨드카드·자원 줄)도 초안 좌표와 몇 px 안에서 맞는다.
다만 초안에 있던 요소 중 **아직 구현되지 않은 것**이 있다.

## 초안과 같은 것
- 배치·크기: 미니맵 350×320(초안 345×313), 정보 패널 760×225(741×218), 초상화 225×225(217×218), 커맨드카드 585×320(576×313).
- 진영 색: 정보 패널·커맨드카드 프레임과 속판, 글자색, 칸색, 단축키색이 초안 팔레트 그대로 바뀐다. 모험가는 하늘색과 흰색, 시그너스는 상아색과 진청색, 에델슈타인은 어두운 철판색이다.
- Maple 글꼴, HP 바 빨강, 스탯 칩 3개(유닛만, 건물은 숨김), 다중 선택 6×2 + 칸별 HP 바, 생산 큐(큰 칸 1 + 작은 칸 3), 커맨드카드 5×2 + 잠금 덮개 + 쿨타임 덮개.

## 이후 추가된 것
- 미니맵 카메라 사각형(스타크래프트처럼 현재 화면 범위 표시), 기능별 커서 — Handoff 12절.
- 미니맵 테두리(아래 표 2번 해결) + 하단 HUD 4px 밀림 수정 — Handoff 13절.

## 초안에는 있는데 없는 것 (중요도 순)
| # | 항목 | 초안 | 실제 | 고치는 방법 |
|---|---|---|---|---|
| 1 | 자원 줄 바탕 | 진영 프레임 판 위 메소·에르다·인구 칸 | 바탕 없이 흰 글자만 맵 위에 뜸. 밝은 맵이나 유닛 위에서 안 읽힐 수 있음 | `CurrencyHUD` 뒤에 기본 스프라이트 판 + 칸 3개 추가, `FactionTheme`에 덧칠 경로 추가 |
| 2 | ~~미니맵 테두리~~ (해결) | 진영 프레임 + "미니맵" 표시 | 지도 이미지만, 테두리 없음 | `PlayMapUI` 뒤 형제로 프레임 판 추가(클릭 좌표 계산에 영향 없음) |
| 3 | 초상화 테두리 | 진영 프레임 + 아래 소유 색 줄 | 유닛 스프라이트만 덩그러니. 선택이 없으면 그 자리가 비어 맵이 보임 | `UnitSpriteUI` 뒤 형제로 프레임 판 + 소유 색 줄 |
| 4 | 진영 장식 | 모험가 단풍잎, 시그너스 금 이중선, 레지스탕스 리벳·커맨드카드 위 주황/검정 줄무늬 | 없음(단색 판) | 금 이중선·주황 띠는 기본 스프라이트 겹침으로 가능. 단풍잎·리벳·줄무늬는 전용 스프라이트 필요 |
| 5 | 커맨드카드 비용·툴팁 | 칸 오른쪽 위 비용, 마우스 올리면 툴팁 | 없음 | 칸에 `Cost` 텍스트 + 공용 툴팁 패널 추가, `UnitActionSpriteChange`에서 채움 |
| 6 | 영웅 정보 | 이름 + (레벨) | 이름이 "영웅"으로만 나옴 | `UnitInfoTextUpdater`에서 HeroData 이름 사용 |
| 7 | 잠금 두 종류 | "준비 중"(빗금)과 "선행 건물 필요"(검은 덮개+자물쇠) 구분 | 덮개 한 종류 + 사유 글자로만 구분 | 빗금 스프라이트 필요(또는 색만 다르게) |

1~3과 6은 기본 스프라이트와 스크립트만으로 고칠 수 있다. 4의 일부와 7은 아트(스프라이트)가 있어야 초안 느낌이 난다.
