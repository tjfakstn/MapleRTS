## 2. 모험가 건설 구조 (사용자 확정)
- **스포아 B 기본**: 세계수의 뿌리(조건 세계수), 전직관의 집(헤네시스 사냥터), 헤네시스 사냥터(헤네시스 전초지), 페리온 채석장(페리온 전초지), 요정의 숲(엘리니아 전초지), 커닝시티 지하철(커닝시티 전초지)
- **스포아 V 고급**: 헤네시스 무기점, 전사의 성소, 마법 도서관, 다크로드의 은신처, 버섯의 성, 엘리니아 마나 제단
- **세계수의 뿌리 → 전초지 변환**: 헤네시스 전초지(조건 없음), 페리온·엘리니아 전초지(헤네시스 사냥터), 커닝시티 전초지(페리온 채석장 또는 요정의 숲)
- **배치 범위** (`BuildZoneLogic.AdvOutpostFor`):
  - 헤네시스 사냥터·무기점·버섯의 성 → 헤네시스 전초지 반경
  - 페리온 채석장·전사의 성소 → 페리온 전초지 반경
  - 요정의 숲·마법 도서관·마나 제단 → 엘리니아 전초지 반경
  - 커닝시티 지하철·다크로드의 은신처 → 커닝시티 전초지 반경
  - 세계수의 뿌리·전직관 → 세계수·뿌리·전초지 반경
- 배치할 때는 해당 전초지 반경 원만 표시되고, 범위 밖이면 "○○ 전초지 주변 범위 안에만 지을 수 있습니다"가 뜸.
- 전초지 4종 자신의 건설 목록은 비어 있음.
- 스포아는 건설을 시작하면 소모됨(기존 그대로).

## 10. 전투 조작 (스타식)
- **우클릭 적** → 바로 추격·공격 (`Unit_Info.RequestSetTarget`이 `Attack()`까지 호출).
- **A** → 공격 커서로 바뀌고 다음 클릭을 기다림(토스트 없음). 좌클릭·우클릭 모두 받음 (`DragComponent` → `Mouse_Command.ExecutePendingAt`).
  - 적(유닛·건물·몬스터) 위 클릭 → 그 대상 공격
  - 땅·아군 클릭 → **어택땅** `Unit_Info.RequestAttackMove`: 가다가 적을 만나면 싸우고, 다 잡으면 목적지로 다시 이동
- **자동 교전** `Weapon.AutoAcquire`(0.3초 주기, 서버):
  - 대기 중이거나 어택땅 중일 때만 동작. 일반 이동 중·일꾼·공격력 0 유닛은 하지 않음
  - 탐색 범위는 max(사거리+1, min(시야, 사거리+3)). 상대 유닛을 먼저 노리고, 없으면 상대 건물
  - 중립 몬스터는 사거리+0.5 안에 붙었을 때만 반격
  - 자동으로 쫓던 대상이 범위+3을 넘어 도망가면 추격을 포기(리시)
- **H 위치 고수** `Unit_Info.RequestHold`: 그 자리에서 사거리 안의 적만 공격하고 쫓아가지 않음. 이동·정지 명령을 받으면 풀림.

## 7. 유닛 고유 능력 (`PlayMap/Ability/UnitAbilityLogic.mlua`)
능력 종류는 시트(UnitCommandData)의 능력 이름으로 정함. 위치 지정형 능력은 단축키를 누르면 커서 위치에 바로 쓰고, 버튼을 누르면 다음 클릭 위치에 씀.

| 능력 | 종류 | 효과 | 재사용 |
|---|---|---|---|
| 강타 | 즉발 | 반경 0.9, 공격력 ×2.5 | 10초 |
| 사격 | 즉발 | 반경 0.6, 공격력 ×3 | 10초 |
| 폭발 | 즉발 | 반경 1.6, 공격력 ×2, 건물 포함 | 14초 |
| 포격·폭격 | 즉발 | 반경 2.0, 공격력 ×2.5, 건물 포함 | 16초 |
| 투척 | 즉발 | 반경 1.2, 공격력 ×1.5 + 설명에 따른 상태이상(독/냉기/저주/복합) | 12초 |
| 감소 | 즉발 | 반경 1.8, 공격력 ×0.5 + 둔화·공속 저하 | 14초 |
| 전격 | 연쇄 | 4명까지 튐, 공격력 ×1.6, 튈 때마다 −15% | 12초 |
| 돌진 | 돌진 | 3칸을 3배 속도로 달려가 도착 지점 반경 1에 공격력 ×2 | 12초 |
| 도발 | 즉시 | 반경 3.5 안 적이 나를 공격하게 함, 내 방어 +4 (5초) | 15초 |

## 추가 수정 (2026-10-06 저녁)
- **영웅은 기본 공격 없음 (스킬 전용)**
  - `Unit_Info.Attack`가 영웅이면 바로 끝남. 자동 교전(`Weapon.AutoAcquire`)도 영웅은 제외.
  - 적을 우클릭하면 그 위치로 이동만 함. 어택땅도 일반 이동으로 처리.
  - 영웅 커맨드카드에서 공격·순찰·위치 고수 칸을 비움. 정보 패널 공격 칸은 "공격 스킬 전용".
- **상대 영웅 체력바가 안 보이던 문제**
  - 원인: `HeroUnitVisual`이 초상화용 스프라이트를 알파 0으로 두는데, `UnitOverlayLogic`이 이걸 "은신 유닛"으로 보고 숨겼음.
  - 수정: 영웅은 이 검사에서 제외.
  - 같이 발견한 것: 내가 넣은 `SpecialAbilityComponent`의 은신 반투명 처리가 영웅 스프라이트 알파를 1로 되돌리던 버그 → 영웅은 건너뛰게 수정.
- **영웅이 모두 "내 아바타"로 보이던 문제**
  - 증상: 각자 화면에서 모든 영웅이 그 화면 주인의 코디로 보임.
  - 원인 추정: 서버가 넣는 `CostumeManagerComponent.DefaultEquipUserId`가 클라이언트 렌더에 반영되지 않고, 로컬 유저 코디로 그려짐.
  - 수정: `HeroUnitVisual.SyncOwnerCostume`(클라)에서 주인 플레이어 엔티티의 장비 17부위를 `GetEquip`로 읽어 영웅에 `SetEquip`하고 `UseCustomEquipOnly=true`로 둠. 로드 전이면 1초마다 재시도하고, 주인이 맵에 없으면 `DefaultEquipUserId`로 대신함. 로그 `[HeroUnitVisual] 주인 코디 적용`.
  - 한계: 경기 중 주인이 코디를 바꿔도 따라가지 않음.
- **유닛 발밑에 가끔 빨간 발톱 자국이 보이던 문제**
  - 그림 정체: 유닛 모델 53개의 `Attack_` 자식(공격 사거리 판정용)에 초기 공격 로직 때 넣은 스프라이트 `354ee1c725674b79812c3a2767c9ba57`(빨간 세 줄 발톱)가 남아 있었음. 평소엔 엔티티 `Visible=false`로 가려져 있었음.
  - 가끔 보인 이유: `VisionLogic.ApplyVisible(e, true)`가 "숨기기 전 기록"이 없을 때(처음 시야에 들어온 상대 유닛·재경기 직후 등) 자식 전부를 `Visible=true`로 켬.
  - 수정 ① `ApplyVisible`은 자신이 숨긴 기록이 있는 자식만 되돌리고, 기록이 없으면 자식을 건드리지 않음.
  - 수정 ② 53개 모델 `Attack_`의 SpriteRUID를 비우고 렌더러를 끔(도구 `메이플RTS_tools/clear_attack_sprite.cjs`). 판정은 TriggerComponent만 쓰므로 영향 없음.

## 3진영 에르다 비용 통일 (2026-10-06 밤, 사용자 확정)
- 기준: 계열 첫 생산 건물 0 / 업그레이드 1 / 최종 테크 2. 유닛은 기본 0 / 중급 1 / 상위 2 / 최종 3까지. 에르다 몬스터 처치 시 3.
- 모험가: 페리온 채석장·요정의 숲·커닝시티 지하철 1→0 (앞에서 반영)
- 시그너스 건물: 여제의 알현실·골렘의 사원·정령의 제단 1→0
- 시그너스 유닛:
  - 플레임·스톰 1→0 (소울·다크니스·라이트닝은 1 유지)
  - 정식기사A 2→1, 상급기사 B·C·D·E 2→1, 상급기사A 5→2
  - 에인션트 골렘·다크골렘 3→2, 믹스골렘 4→3, 이프리트 4→3
- 에델슈타인 건물: 폐광 무기고·비행선 격납고 1→0
- 에델슈타인 유닛: 훈련로봇0(전투기)·순찰로봇(수송) 1→0, 게오르크 4→3
- 업그레이드 건물(1)과 최종 테크(2)는 세 진영 모두 그대로.

## Maker에서 확인할 것 (권장 순서)
1. **Refresh**: 신규 `UpgradeLogic`, `UnitAbilityLogic`, `PlayerInfo`(SyncTable 추가)가 인식되는지 확인.
2. 우클릭 공격, A+클릭(적/땅), 대기 유닛 자동 반격, H 위치 고수. 로그 `[Weapon] 자동 교전`, `[Unit_Info] 어택땅`으로 확인.
3. 모험가: 세계수의 뿌리 "전초지 변환" → 전초지 4종, 스포아 B/V 12종, 지역 건물이 해당 전초지 반경 밖에서 거부되는지, 전초지 선택 시 건설 버튼이 없는지 확인.
4. 업그레이드 건물 W/A 연구 → 완료 토스트 → 유닛 정보에 "+N" 표시.
5. 능력: 갑옷버섯 D 도발, 와일드보어 C 돌진, 이블아이 I 투척, 방어시스템 O 시즈모드, 셰이드 K 은신.
6. 전직관 버튼 아이콘 4개.
7. 일꾼 A 공격.
8. 영웅: 적 우클릭 시 이동만 하는지, Q~T 스킬로만 피해가 들어가는지, 상대 영웅 체력바(피해 입으면) 보이는지, 영웅이 반투명/네모 스프라이트로 보이지 않는지.
10. 2명 이상 접속해서 서로의 영웅이 각자 자기 코디로 보이는지.
9. 에르다 몬스터 머리 위 체력바가 항상 보이는지(위치는 실기에서 조정 필요할 수 있음).
