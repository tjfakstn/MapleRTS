## §1 힐러 (파란버섯·물도둑)

- 에너지: 최대 200, 시작 50, 초당 0.8 충전, 에너지 1당 2 회복(`SpecialAbilityComponent` HealMaxEnergy/HealStartEnergy/HealEnergyRegen/HealPerEnergy). 회복량 = min(AbilityValue, 잃은 체력, 에너지×2), 실제 회복한 만큼만 에너지 소모. 정보창에 "에너지 n / 200".
- 자동 치유는 다른 힐러를 대상에서 뺌(힐러끼리 서로 무한 회복 방지). 직접 지정은 허용.
- 치유 지정(L → 우클릭) 대상은 **다른 명령을 해도 그 대상이 죽을 때까지 따라감**. 체력이 가득해도 해제 안 함. 사거리 60 %보다 멀어지면 다시 붙음(1초 간격).
- 치유 사거리(4.0)와 회복량(파란버섯 10 / 물도둑 8 매초)은 그대로 — 에너지로 지속량이 초당 약 1.6으로 제한됨.

# 적군·아군 유닛 구분 (2026-10-07 4차)
- 원인: 소유 구분이 **선택했을 때 링 색**(초록/빨강)뿐이고, 평소엔 아무 표시가 없었다. 체력바 색도 주인과 무관하게 체력 비율(초록→노랑→빨강). 같은 진영끼리 붙으면 그림까지 같아 구분 불가.
- 반영: `UnitOverlayLogic` — 유닛(영웅 포함)은 **선택하지 않아도 발밑에 옅은 소유 링**(불투명도 0.45): 내 유닛 초록 / 상대 빨강 / 중립(에르다 몬스터) 노랑. 선택하면 지금처럼 진하게. 건물은 예전처럼 선택했을 때만. 시야 밖·은신(미탐지) 적은 링도 숨김(기존 규칙 그대로).
- 조절: 컴포넌트 속성 `ShowOwnerRing`(끄기), `OwnerRingAlpha`(진하기).
- Maker 확인: 아군·적 유닛이 섞였을 때 링 색으로 바로 구분되는지, 링이 너무 진하거나 흐리지 않은지.

- 바뀐 것(에델슈타인만 — 모험가·시그너스는 그대로):
  1. **훈련로봇이 곁에 붙어 있는 동안에만 건설 진행**(`Structure_Info.TickConstruction`). 체력은 **10 %에서 시작해 진행만큼 차오름**(테란 건물처럼).
  2. 훈련로봇은 건설에 묶이지 않음 — 다른 명령을 받아 떠나거나 죽으면 **건설 중단**(남은 시간 고정, 정보창 "건설 중단 · 훈련로봇으로 우클릭해 이어 짓기").
  3. **다른 훈련로봇으로 미완성 건물을 우클릭하면 이어 지음**(`WorkerBuildState.RequestResumeBuild` — 건물 곁으로 가면 자동 재개).
  4. 일꾼 정보창과 건물 정보창이 **같은 남은 시간**(`Structure_Info.RemainingBuildTime`). 진행 바도 같음.
  5. 짓는 동안 훈련로봇 작업 모션(제자리 걷기 + 불꽃)은 실제로 진행 중일 때만(`WorkerBuildState.IsRepairing`).
  6. 건설 연출 그림은 완공될 때까지 유지(멈춰서 늦게 끝나도).
- 새 동기화 값: `Structure_Info.NeedsBuilder/ConstructionPaused/ConstructionRemaining`, `WorkerBuildState.BuildTarget/IsRepairing` — Maker Refresh 필요.

### Maker 확인 (12차)
1. 훈련로봇으로 건설 → 건물 체력이 10 %에서 차오르고, 일꾼·건물 정보창 남은 시간이 같음(도중에 일꾼을 선택해도).
2. 건설 중 훈련로봇에게 이동 명령 → 건설 중단(남은 시간 멈춤), 다시 그 건물 우클릭 → 이어 짓기.
3. 건설 중 훈련로봇 사망 → 중단, 다른 훈련로봇 우클릭으로 재개.
4. 완공 시 기능 활성(생산 버튼 등), 작업 모션 종료.

# 치유 지정 · 유닛 자살 제거 (2026-10-07 13차)
1. **치유 대상을 계속 따라가며 다른 명령을 안 들음**: 다른 명령으로 지정이 풀리는 수정은 9차에 이미 들어 있음(팀 테스트가 9차 이전 파일이었을 가능성). 추가로 찾은 함정 — L(치유) 후 아군을 **좌클릭**하면 무시되고 지정 모드가 남아, **그다음 우클릭 이동 명령이 치유 대상 지정으로 먹혀** 명령을 안 듣는 것처럼 보였음 → L 후 좌클릭으로도 치유 대상 지정(`DragComponent`).
2. **유닛 자살 기능 제거**: 유닛 커맨드카드의 "취소"(즉사 + 비용 환불) 칸 삭제, 서버(`SpawnUnit.RequestCancelEntity`)도 유닛 취소 요청 거부. 건물 취소(환불)는 그대로.

### Maker 확인 (13차)
1. L → 아군 좌클릭/우클릭으로 치유 지정 → 이동 명령 시 지정 해제되고 바로 이동.
2. 유닛 선택 시 취소 칸 없음, 건물은 취소 칸 있음.

# 건설 진행 바 · 에델슈타인 건설 방식 되돌림 (2026-10-07 14차)
- 피드백: 건물 위에 검은 막대가 뜸 → 짓는 중인 건물(테란식, 체력 10 %에서 시작)이 "다친 건물"로 보여 빈 체력바가 계속 떠 있던 것.
- 사용자 결정: 1번(짓는 중엔 건설 진행 바, 목업 `Docs/preview/build_progress_bar.html`) + **에델슈타인도 다른 진영처럼** 짓기.
- 바뀐 것:
  1. **건설 진행 바(세 진영 공통)**: 짓는 중인 건물은 체력바 대신 **노란 바**(길이 = 지어진 비율)를 항상 보여 줌. 완공되면 사라지고, 이후엔 지금처럼 다쳤을 때만 플레이어 색 체력바(`UnitOverlayLogic.BarBuild`, `Structure_Info.RemainingBuildTime` 기준). 진행률·남은 시간 글자는 머리 위가 아니라 선택 시 정보창에 표시(머리 위 글자는 모델마다 텍스트 자식이 필요해 이번엔 넣지 않음).
  2. **12차 테란식 건설 되돌림**: 훈련로봇은 건설을 시작하면 바로 풀려나 다른 명령 수행(시그너스와 같음), 건물은 시간이 지나면 완성, 체력도 처음부터 가득. 작업 모션(제자리 걷기 + 불꽃)도 안 나옴(`SpawnUnit.RequestBuildStructure` — `StartBuild(..., Cyg 또는 Ede)`).
  3. 12차에서 넣은 이어 짓기·중단 코드(`Structure_Info.TickConstruction`, 미완성 건물 우클릭 재개 등)는 `NeedsBuilder`가 켜지지 않으므로 동작하지 않음(남겨 둠). 일꾼·건물 정보창 남은 시간 일치 수정은 그대로 유효.

### Maker 확인 (14차)
1. 세 진영 각각 건물 건설 → 머리 위에 노란 바가 0 %부터 차오르고 완공 시 사라짐. 검은 막대 없음.
2. 완공 건물을 공격 → 다쳤을 때 플레이어 색 체력바.
3. 에델슈타인 훈련로봇이 건설 시작 후 바로 다른 명령을 받는지, 건물은 혼자 완성되는지.
4. 안개 속 적 건설 중 건물의 바가 보이지 않는지.

## 14차 — 일꾼 최대 수 + 에르다 채집 건물 영역 제한 해제 (2026-10-07, 제출 전)
사용자: "일꾼에 제한이 없어서 돈이 놀아 물량으로 밀면 되는 문제" → "시그너스·모험가 에르다 채집 건물만 건설 영역 조건 없애고 일꾼 수에 제한".
- 일꾼 최대 수: `SpawnUnit.WorkerLimit = 20`(인스펙터 조정, 0 이하 = 제한 없음). 살아있는 내 일꾼(RoleKey Worker) + 생산 대기 중인 일꾼(`_T.pending[token].worker`)이 한도면 생산 거부 + 토스트 "일꾼은 최대 20명까지 만들 수 있습니다 (n/20)". 새 메서드 `SpawnUnit.CountWorkers(map)`.
- 에르다 채집 건물: 모험가(세계수·뿌리·전초지 반경)·시그너스(신수·신수의 가호 반경) 영역 조건을 적용하지 않음 — 서버 `SpawnUnit.RequestBuildStructure`의 zoneProviders, 클라 `BuildModeLogic`의 고스트 providers를 에르다 채집 건물이면 "". 에르다 몬스터 스포너 영역 안 조건·안개(탐사한 곳) 조건·겹침 조건은 그대로.
- Maker에서 확인할 것: 일꾼 20명(대기 포함)에서 생산 시 토스트 / 일꾼이 죽거나(모험가는 건물로 변하면) 다시 뽑힘 / 모험가·시그너스로 영역 밖 에르다 소환지에 채집 건물 고스트가 초록 → 건설됨 / 소환지 밖은 여전히 빨강.
