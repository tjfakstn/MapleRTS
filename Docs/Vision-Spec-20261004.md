# 시야 스펙 v1 — 건물·유닛 (2026-10-04)

- 상태: **2026-10-04 코드·CSV 적용 완료(다크니스 시야 감소·소울 U 토글 제외). 안개 오버레이는 2026-10-05 추가 — `FogOfWar-20261005.md`.** 구현 요약은 `Handoff-20261004.md` 8절. 1~5절 건물, 6~9절 유닛·영웅·탐지.
- 현재 코드에는 시야 개념이 없다(유닛 CSV `vision` 열은 있으나 아무도 읽지 않고, 건물은 열 자체가 없음). 모두가 모든 것을 보는 상태.

## 1. 단위와 변환

| 항목 | 값 |
|---|---|
| 시야 단위 | world unit **반지름** (1 unit = 100px, PC 화면 가로 12.8 unit) |
| CSV 저장값 | `vision` 열, 유닛 시트와 같은 스케일(200~300) |
| 변환 | **시야 반지름 = vision ÷ 50** (사거리는 ÷100이므로 헷갈리지 말 것) |
| 기준 | 스타1 시야 7 ≈ 화면 가로 20칸의 35% → 이 게임 화면 12.8 × 0.35 ≈ 4.5 |

## 4. 규칙

1. **건설 중**(`IsUnderConstruction == true`)에는 완공값의 **50%**. 스타1도 건설 중 건물은 시야가 좁다. 일꾼이 붙어 있으니 실제론 일꾼 시야가 보완한다.
2. **파괴**(`IsDestroyed == true`)되면 즉시 시야 0. 잔해는 시야를 주지 않는다.
3. **소유자 기준**. 내 건물만 내게 시야를 준다. 팀전이 생기면 팀 단위로 바꾼다.
4. **탐지**: `Tech`/`FinalTech` 건물은 시야 반지름 안의 은신 유닛(셰이드·정식기사A·상급기사A·추적자)을 드러낸다. 다른 건물은 탐지 없음. 유닛 쪽 탐지기(소울·영웅)는 유닛 시야 문서에서 정한다.
5. **고지대·지형 차폐 없음**. 평지 타일맵이라 원형 시야만 쓴다.
6. **수치는 밸런스 전 초기값**. 플레이 테스트에서 "본진 앞 입구가 안 보인다"가 나오면 `District`/`Territory`를 올리고, "건물 하나로 적 기지가 다 보인다"가 나오면 `HQ`를 내린다. 한 등급씩만 움직인다.

## 5. 적용 방법 (구현 때 할 일)

| 순서 | 파일 | 내용 |
|---|---|---|
| 1 | `Structure_Stat_DataSet/{Adv,Cyg,Res}_Structure_Stat_DataSet.csv` | `vision` 열 추가, 3절 값 입력 (`.userdataset`은 Maker Refresh가 재생성) |
| 2 | `RootDesk/MyDesk/PlayMap/StructureComponent/Structure_Info.mlua` | `property number Vision = 4.5` 추가 |
| 3 | `RootDesk/MyDesk/SetCampManager_Logic.mlua` `ParseStructureTable` | `vision = tonumber(temp:GetCell(idx, "vision"))` 읽기(열 없으면 nil 허용) |
| 4 | `RootDesk/MyDesk/PlayMap/Player_Scripts/SpawnUnit.mlua` `ApplyStructureData` | `info.Vision = (data.vision or 225) / 50` 주입. 본진은 `LobbyController.SpawnPlayerHQ`가 같은 함수를 쓰므로 자동 적용 |
| 5 | `메이플RTS_건물스펙_v1.xlsx` | 시트에도 `시야` 열 추가(기록용) |

실제 "보임/안 보임" 판정과 안개는 유닛 시야 스펙과 함께 `VisionLogic`(클라이언트 전용)에서 한 번에 구현한다. 건물은 그 로직에 `Structure_Info.Vision`을 공급하는 역할만 한다.

| 구분 | 대상 | 반지름 |
|---|---|---:|
| 은신 유닛 | 셰이드, 정식기사A, 상급기사A (`RoleKey = AerialStealth`), 추적자 레드(RoleKey 보정 필요) | — |
| 탐지기 (유닛) | 소울(U 시야 공유 켠 상태), 영웅 | 시야와 동일 (6.0) |
| 탐지기 (건물) | `Tech` / `FinalTech` 건물 | 시야와 동일 (5.0) |

1. 은신 유닛은 **시야 안에 있어도 탐지기 반지름 밖이면 안 보인다.** 공격 대상도 못 된다(서버 `CanTargetForCombat`에 "은신 && 탐지 안 됨 → 거부" 추가).
2. 은신 유닛이 공격해도 드러나지 않는다(스타1과 동일). 드러나는 조건은 탐지기뿐.
3. 추적자 레드는 시트가 "은신 저격"인데 CSV `RoleKey`가 `RangedBasic`이다. 은신을 주려면 `UnitCommandData`의 K 능력처럼 **별도 `IsStealth` 열**을 두는 게 맞다. `RoleKey`를 `AerialStealth`로 바꾸면 `CombatConfig`가 원거리+투사체로 해석해 정식기사A 문제(리뷰 3절)가 재발한다.

## 9. 유닛 시야 규칙

1. **사망 시 즉시 0.** `IsDead`면 시야원에서 제외.
2. **공중·지상 구분 없음.** 같은 원.
3. **이동 중에도 즉시 반영.** 판정 주기 0.2초(클라이언트 `VisionLogic`), 미니맵 점·본체·체력바·선택 링을 함께 끈다.
4. **다크니스 "시야 감소"(능력 I)**: 맞은 적 유닛 시야 **−50%**, 지속 `AbilityDuration`. 0.5 미만으로는 안 내려간다(자기 발밑은 본다).
5. **소울 "시야 공유"(능력 U)**: 켜면 소울 시야 6.0 + 탐지. 끄면 일반 공중 5.2 + 탐지 없음. 스타1 옵저버는 상시지만, 이 게임은 U 토글이 시트에 있으니 토글로 둔다.
6. **시야 공유 범위는 플레이어 단위.** 팀전이 생기면 팀 단위로 확장.
