# 전달 — Practice 2 통합본 (10-04 전달분 + 10-05 추가분, 145개 파일)

10-04 전달분과 10-05 추가분(시야·은신, 진영별 BGM, 유닛 사운드, 대기실 v3·준비 완료 버튼, 미니맵 카메라 사각형, 기능별 커서)을 하나로 합친 **통합본**이다. 겹치는 파일은 최신(10-05) 버전만 넣었다. 10-04 zip을 이미 적용했어도, 안 했어도 이것만 덮어쓰면 된다.

## 적용 방법
1. 이 zip의 폴더 구조 그대로 Maker 프로젝트 루트(Practice)에 덮어쓴다. 파일명은 NFC(윈도우 호환)로 저장했다.
2. `.codeblock`은 포함하지 않았다. Maker에서 **Refresh**하면 새 프로퍼티(@Sync 등)에 맞춰 자동 재생성된다.
3. 신규 스크립트 4개가 있어 Refresh 전에는 `_VisionLogic`·`_SoundResources`·`_BgmController`·`_CursorLogic`이 없어 빌드 에러가 난다. Refresh 후 Error 0인지 먼저 확인.
4. 재테스트는 `Docs/Handoff-20261004.md` 7절(경기 흐름) → 8절(시야) → 9절(BGM) → 10절(유닛 사운드) → 11절(대기실 v3·준비 버튼) → 12절(미니맵 카메라 사각형·커서) 순서.
